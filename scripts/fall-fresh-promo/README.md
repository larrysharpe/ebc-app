# Fall Fresh 2026 — video assembler

Stays here on purpose (large `.venv` and source clips). Browse it from the campaign index:

`scripts/media-campaigns/2026-fall-fresh/` (shortcut: `promo/` → this folder)

## Rebuild

```bash
cd "scripts/fall-fresh-promo"
./run.sh build
```

Upload from `output/`:

- `fall-fresh-reel-15.mp4` — Facebook / Instagram / YouTube
- `fall-fresh-main-30.mp4` — landscape
- `fall-fresh-main-30-vertical.mp4` — vertical 30s
